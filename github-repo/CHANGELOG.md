# Changelog

All notable changes to SignLess will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-10-06

### Added
- Dynamic transaction amounts for enhanced security
- Timestamp-based unique modifiers per session
- Improved verification tolerance (0.000001 SOL)
- Enhanced CORS configuration with multi-origin support
- Session cleanup mechanism
- Comprehensive API documentation
- Deployment guides for multiple platforms

### Changed
- Verification amount now includes dynamic component
- Session ID format includes timestamp
- Improved error handling and responses
- Updated dependencies to latest versions

### Fixed
- CORS wildcard support for development
- Precision issues with amount verification
- Session expiry cleanup

## [1.0.0] - 2025-10-05

### Added
- Initial release
- Basic authentication via micro-transactions
- RESTful API endpoints
- Session management
- Solana blockchain integration
- Environment-based configuration
- README and documentation
- MIT License

### Security
- Secure session handling
- Transaction verification
- CORS protection
